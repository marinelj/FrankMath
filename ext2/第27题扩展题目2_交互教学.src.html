题目

【新定义】若点 Q 满足 ∠PAQ = 90° 且 AQ = AP，则称点 Q 为点 P 关于点 A 的链垂点。（也就是把点 P 绕点 A 旋转 90° 得到点 Q，顺时针、逆时针都可以。）

如图，在平面直角坐标系中，O 为原点。

(1)① 已知点 A(2,1)，点 P(5,4)，求点 P 关于点 A 的链垂点的坐标；

(1)② 已知点 A(1,2)，点 B(5,6) 是点 A 关于点 C 的链垂点，且点 C 在点 A 的正上方，求点 C 的坐标。

(2) 图形 H 是顶点为 (−4,0)、(4,0)、(0,4) 的等腰直角三角形的边界（不含内部）。点 E 的坐标为 (0, t)。点 D 在线段 G 上运动，G 的两个端点分别为 (2,1) 和 (2,2)。若点 Q 是点 D 关于点 E 的链垂点，且点 Q 恰好落在图形 H 上，求 t 的取值范围。

(1)① P(5,4) 关于 A(2,1) 的链垂点 (−1,4) 或 (5,−2)
(1)② B(5,6) 为 A(1,2) 关于 C 的链垂点 C = (1,6)

定义与注意

若 Q 是点 P 关于点 A 的链垂点，则 ∠PAQ = 90° 且 AP = AQ。把从 A 到 P 的方向绕 A 逆时针转 90°，或顺时针转 90°，就得到 Q。第 (2) 问中「落在图形 H 上」指三角形三条边上的点，不包括只落在内部的点。左边是连接 (−4,0) 与 (0,4) 的线段：向右 4、向上 4，所以点满足「纵坐标 = 横坐标 + 4」，并且 −4 ≤ x ≤ 0；右边向右 4、向下 4，满足「纵坐标 = 4 − 横坐标」，并且 0 ≤ x ≤ 4。答案是两段的并，中间 (2, 7/2) 没有解，不要写成一整段 [−2, 4]。
