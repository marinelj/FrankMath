# 第27题扩展题目2（已锁定，不得改答案）

## 题目原文（学生可见，不要出现密码，也不要在题干里写答案）

【新定义】若点 Q 满足 ∠PAQ = 90° 且 AQ = AP，则称点 Q 为点 P 关于点 A 的链垂点。（也就是把点 P 绕点 A 旋转 90° 得到点 Q，顺时针、逆时针都可以。）

如图，在平面直角坐标系中，O 为原点。

(1)① 已知点 A(2,1)，点 P(5,4)，求点 P 关于点 A 的链垂点的坐标；

(1)② 已知点 A(1,2)，点 B(5,6) 是点 A 关于点 C 的链垂点，且点 C 在点 A 的正上方，求点 C 的坐标。

(2) 图形 H 是顶点为 (−4,0)、(4,0)、(0,4) 的等腰直角三角形的边界（不含内部）。点 E 的坐标为 (0, t)。点 D 在线段 G 上运动，G 的两个端点分别为 (2,1) 和 (2,2)。若点 Q 是点 D 关于点 E 的链垂点，且点 Q 恰好落在图形 H 上，求 t 的取值范围。

## 锁定答案

- (1)① (−1,4) 或 (5,−2)
- (1)② C = (1,6)（必须先找出 (1,6) 和 (5,2)，再按「C 在 A 的正上方」舍去 (5,2)）
- (2) t ∈ [−2, 2] ∪ [7/2, 4]
  - 中间 (2, 7/2) 是空的。例如 t = 5/2 时，无论 D 取在 G 的哪里，Q 都落不到 H 上。
  - 不要写成 [−2, 4]。

## 第 (2) 问参数与公式（讲解和滑块用）

- E = (0, t)，t 不加正负限制（E 在整条 y 轴上，这条线正好是三角形的对称轴）
- 用 s 表示 D 在 G 上的位置：D = (2, s)，1 ≤ s ≤ 2。s = 1 时 D 在 (2,1)，s = 2 时 D 在 (2,2)。
- s 不是题干里的字母，必须在探索区滑块旁写清定义。画布提示不要只说「改 s」，要说「改 D 的位置」或同时出现定义。
- Q₊（逆时针）= (t − s, t + 2)
- Q₋（顺时针）= (s − t, t − 2)
- H 的三边：
  - 底边：y = 0，−4 ≤ x ≤ 4
  - 右边：连接 (4,0) 与 (0,4)，满足 y = 4 − x，0 ≤ x ≤ 4
  - 左边：连接 (−4,0) 与 (0,4)，满足 y = 4 + x，−4 ≤ x ≤ 0
  - 讲解里用「向右多少就向上（或向下）多少」来说明斜边，不要把一次函数当成初二上新知识来讲。不要用勾股定理，不要写根号。

## 八种（六种）情形的结论

逆时针 Q₊：
1. 落到底边 y = 0：t = −2，x = −2 − s ∈ [−4, −3]，成立。
2. 落到右边 y = 4 − x：t = 1 + s/2 ∈ [3/2, 2]，x = 1 − s/2 ∈ [0, 1/2]，成立（已被 [−2,2] 包含）。
3. 落到左边 y = 4 + x：必须 s = 2，此时 t ∈ [−2, 2]，成立。

顺时针 Q₋：
4. 落到底边 y = 0：t = 2，x = s − 2 ∈ [−1, 0]，成立（已被 [−2,2] 包含）。
5. 落到右边：会得到 s = 6，与 1 ≤ s ≤ 2 矛盾，不成。
6. 落到左边：t = 3 + s/2 ∈ [7/2, 4]，x = s/2 − 3 ∈ [−5/2, −2]，成立。

## 必须演示的端点（讲解和图上都要能对准）

- t = −2，D = (2,1)，逆时针，Q = (−3, 0)，在底边上
- t = −2，D = (2,2)，逆时针，Q = (−4, 0)，在左下顶点
- t = 2，D = (2,2)，逆时针，Q = (0, 4)，在直角顶点
- t = 2，D = (2,1)，顺时针，Q = (−1, 0)，在底边上
- t = 3/2，D = (2,1)，逆时针，Q = (1/2, 7/2)，在右边上
- t = 7/2，D = (2,1)，顺时针，Q = (−5/2, 3/2)，在左边上
- t = 4，D = (2,2)，顺时针，Q = (−2, 2)，在左边上
- t = 5/2（空隙例子）无解

## 讲解步骤（每问 5 步，口语要自然流畅，不要人机味）

(1)①：先分清中心是 A 不是原点；指出 AP 不是横平竖直，而是向右 3、向上 3；逆时针得到 (−1,4)；顺时针得到 (5,−2)；两个都要保留，并核对等长、直角。

(1)②：读语序，中心是 C，三角形 ACB 是等腰直角，直角在 C，斜边 AB；AB 从 (1,2) 到 (5,6)，中点 M = (3,4)，斜边「向右 4、向上 4」，一半是向右 2、向上 2，垂直平分线方向是向左 2、向上 2（或相反）；两个可能是 (1,6) 和 (5,2)；C 在 A 的正上方，留下 (1,6)；代回检验：C 到 A 是竖直向下 4，到 B 是水平向右 4。

(2)：先看清等腰直角三角形和对称轴（y 轴），以及 D = (2,s)、1 ≤ s ≤ 2，E = (0,t)；写出 Q₊、Q₋；逆时针落到左边或底边（并提右边那一段也在 [−2,2] 里），得到 t ∈ [−2, 2]；顺时针落到左边，得到 t ∈ [7/2, 4]；强调中间 (2, 7/2) 不能连上，t = 5/2 无解。
