# FrankMath

初中几何「链垂点」交互教学材料：第 27 题原题，以及两道扩展练习。每道题都是可离线打开的独立 HTML 网页，带动画讲解。

## 目录

- [`q27-原题/链垂点_交互教学.html`](q27-原题/链垂点_交互教学.html)：第 27 题修订版交互页
- [`ext1/第27题扩展题目1_交互教学.html`](ext1/第27题扩展题目1_交互教学.html)：扩展题目 1（外围正方形）
- [`ext2/第27题扩展题目2_交互教学.html`](ext2/第27题扩展题目2_交互教学.html)：扩展题目 2（等腰直角三角形）

用浏览器直接打开对应的 HTML 即可，不需要服务器。各目录里还有源码、语音素材、验算脚本和修订说明，方便以后改题或重新打包。

- 扩展题目 2：`1111`

## 教师参考答案

**第 27 题原题**

- (1)①：`(-1, 2)` 或 `(1, -2)`（圆心是 O，不是 A）
- (1)②：`C = (1, 4)`
- (2)：`t ∈ [-3, -1]`

**扩展题目 1**

- (1)①：P 关于 A 的链垂点是 `(2, 5)` 或 `(2, -1)`
- (1)②：`C = (3, 4)`（舍去 `(-1, 4)`）
- (2)：`t ∈ [-4, -3] ∪ [-2, -1]`，中间 `(-3, -2)` 是空的，不要连成 `[-4, -1]`

**扩展题目 2**

- (1)①：`(-1, 4)` 或 `(5, -2)`
- (1)②：`C = (1, 6)`（先得到 `(1, 6)` 和 `(5, 2)`，再按「C 在 A 的正上方」舍去 `(5, 2)`）
- (2)：`t ∈ [-2, 2] ∪ [7/2, 4]`，中间 `(2, 7/2)` 是空的，不要连成 `[-2, 4]`

## 重新打包扩展题 2

在 `ext2/` 目录修改源码后，执行：

```bash
node pack.mjs
```

打包脚本只用查找和切片拼接，不要改成正则替换。
