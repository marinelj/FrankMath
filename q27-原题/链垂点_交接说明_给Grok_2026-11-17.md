## 3. 原题数学定义与准确结果（必须遵守）

原题定义：对点 `P` 和点 `A`，若存在 `Q` 满足 `∠PAQ=90°` 且 `AQ=AP`，则 `Q` 是 `P` 关于 `A` 的「链垂点」。也就是说 **A 是旋转中心、P 是被旋转点**，存在顺时针与逆时针两种结果。

设 `A=(a,b)`、`P=(p_x,p_y)`，向量 `v=P−A=(dx,dy)`，则

- **逆时针 +90°**：`Q = A + (-dy, dx)`；
- **顺时针 −90°**：`Q = A + (dy, -dx)`。

### (1)① 原题：点 A=(2,1) 关于点 O 的「链垂点」

**注意原文是「点 A 关于点 O」，旋转中心为 `O=(0,0)`，不是坐标为 `(2,1)` 的点 A。**

`OA=(2,1)`：

- 逆时针：`(2,1) → (-1,2)`；
- 顺时针：`(2,1) → (1,-2)`。

**正确答案：`(-1,2)` 或 `(1,-2)`。**

本项目曾短暂出现 `(1,3)`、`(3,-1)` 的错误答案，那是 **错误地以 `(2,1)` 为中心旋转 O** 的结果。**绝不可继续显示为原题答案。**

### (1)② 原题：B=(5,3) 是 O 关于 C 的「链垂点」，C 在 x 轴上方

满足 `CO=CB` 且 `CO ⟂ CB`；以 `OB` 为斜边的直角等腰三角形。`OB` 中点为 `M=(2.5,1.5)`，两个候选直角顶点：

- `C1=(1,4)`；
- `C2=(4,-1)`（不满足 y>0）。

**正确答案：`C=(1,4)`。** 可验算 `CO=(-1,-4)`，`CB=(4,-1)`，点积 `0`，长度同为 `√17`。

### (2) 图形 G、H，求 t 的范围

原题：`G` 是端点 `(1,0)`、`(2,1)` 的线段，`H` 是以 `O` 为中心、边平行坐标轴、边长 6 的**正方形边界**；`D` 在线段 `G` 上移动，`E=(0,t)` 且 `t<0`，要求存在 `D` 使 **D 关于 E 的某个链垂点 Q 恰好在 H 上**。

参数化：

```text
D = (1+s, s), 0 ≤ s ≤ 1
E = (0,t), t < 0
ED = (1+s, s-t)
```

两种旋转后的点：

```text
逆时针 +90°：Q₊ = (t-s, 1+s+t)
顺时针 −90°：Q₋ = (s-t, t-1-s)
```

`H` 四边分别是 `x=-3`, `x=3`, `y=-3`, `y=3`，并且另一坐标必须处于 `[-3,3]`。**不能仅判断 `-3≤x,y≤3`，因为这会把内部点错误算入。**

分支 1：逆时针 `Q₊` 落在 **左边界** `x=-3`：

```text
t-s = -3  =>  s=t+3
0≤s≤1    =>  -3≤t≤-2
Q₊=(-3,2t+4), 纵坐标在 [-2,0] 内
```

分支 2：顺时针 `Q₋` 落在 **下边界** `y=-3`：

```text
t-1-s = -3  =>  s=t+2
0≤s≤1      =>  -2≤t≤-1
Q₋=(2,-3), 横坐标有效
```

合并：**`t ∈ [-3,-1]`**，两端点都包含。两条分支在 `t=-2` 处衔接，**此时有两套不同的 D 和 Q**：

```text
t=-2：逆时针 s=1 => D=(2,1), Q=(-3,0)
t=-2：顺时针 s=0 => D=(1,0), Q=(2,-3)
```

额外端点：

```text
t=-3 => s=0, 逆时针, D=(1,0), Q=(-3,-2)
t=-1 => s=1, 顺时针, D=(2,1), Q=(2,-3)
```

**还应穷举/证明其它边界与 t<0、0≤s≤1 不兼容，而不是仅陈述「其他边不可能」。** 这是可供 Grok 提升严谨性的内容。
